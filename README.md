# Aristocrat Research - Next.js Recreation

A Next.js recreation of the Checkpoint Research website, rebranded as **Aristocrat Research**.

## Features
- Home page with hero, problems, track record, services overview
- About Us
- Services (detailed)
- How It Works (7-step process)
- Partner Insights (testimonials by industry)
- Contact page with form

## Setup
1. `cd aristocrat-research`
2. `npm install`
3. `npm run dev`
4. Open http://localhost:3000

## Styling
- Tailwind CSS
- Blue primary color matching the original modern aesthetic
- Responsive design

## Images
For production, replace the logo placeholder in Header with a proper logo. Generate or add images to `/public` for heroes, team, industry icons.

Original site content adapted; company name, emails, etc. updated to Aristocrat Research.

## Notes

- Success-fee model and stats preserved from original
- Expand team bios, FAQs, blog as desired
